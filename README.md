## vue-paged

**vue-paged** is a tiny wrapper around [pagedjs](https://pagedjs.org) for Vue 3. It renders your HTML into paged content so you can preview it or export as pages.

### Example
```vue
<script setup lang="ts">
import Paged from 'vue-paged';
</script>

<template>
  <Paged>
    <div class="print-content">
      <!-- your printable markup -->
    </div>
  </Paged>
</template>
```

## Installation

1. Install **dependencies**:

```shell
npm i vue-paged
```

2. **You're all set!**
